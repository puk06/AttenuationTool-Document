# 拡声エリアに

:::info
エリア内に入った人の声が、エリア外にいる人に拡声されて聞こえるようになる部屋です。

貫通させたい防音室も指定できます！
:::

ここでは、防音室を拡声エリア仕様に変える方法について解説します。

## 手順

1. ヒエラルキー内の適用したい防音室オブジェクト上で右クリック
2. `防音室ギミック/防音室のカスタム/拡声エリアに変更` をクリック

## 他の防音室内から聞こえるようにする

聞こえるようにしたい防音室をSimple Amplification Areaコンポーネントの `Penetration Areas` に追加することで、他の防音室内からも聞こえるようになります.
